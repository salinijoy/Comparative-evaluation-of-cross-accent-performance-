# A comparative evaluation of cross-accent performance in automatic speech recognition systems using whisper, wav2vec 2.0 and google speech API

## Project Overview
This repository contains the implementation work on cross-accent Automatic Speech Recognition (ASR) systems.
The study compares the performance of three ASR approaches:

- Whisper
- Wav2Vec 2.0
- Google Speech API

## Dataset
The experiments use the AccentDB dataset.
